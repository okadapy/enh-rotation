# Дорожная карта: DoubtMyRotation как полноценный аддон

Источник: два ревью от 2026-10-01 — глазами опытного энха (рейды, симы) и новичка (прокачка 40–60, данжи по поиску группы). Аура WeakAuras остаётся и релизится параллельно; всё ниже — только для аддона, если не сказано иначе (у ауры потолок длины строки импорта).

Объём: S — до дня, M — 2–4 дня, L — неделя и больше.

## Этап 0 — аддон (план `docs/superpowers/plans/2026-10-01-addon.md`)

Тот же движок, своя рамка, SavedVariables, `/dmr`, окно настроек в Interface → AddOns (General / Combat / Advanced), релиз ауры и аддона одной версией.

## Этап 1 — меньше внимания на ленту, понятнее почему

Сделано по плану `docs/superpowers/plans/2026-10-01-stage1-focus.md`, кроме строки «Разбор после боя» — она ещё впереди.

Нужно обоим: опытному — не отводить глаза от своей панели, новичку — не искать иконку по панели.

| Что | Кому | Объём | Как ложится на код |
|---|---|---|---|

Каждое изменение формулы — со сверкой с wowsims (`spec/wowsims_spec.lua`), без подгонки под отдельные состояния (правило из `AGENTS.md`).

## Потом, по желанию

- Таймеры DBM/BigWigs (придержать волков и элементаля до фазы, поправить время до смерти по смене фазы) — API колбэков их версий для 3.3.5a смотреть по коду установленных аддонов; только как необязательная надстройка. M.
- OmniCC (иконке — `CooldownFrameTemplate`, подхватит сам), ButtonFacade (Masque в 3.3.5a нет). S.
- История по боссам и статистика за сессию — продолжение разбора после боя. M.
- Русский клиент: таблица переводов `L[…]` по `GetLocale()` — отложено решением пользователя (2026-10-01); правило «тексты в игре на английском» пока в силе.
- Профили по сложности и размеру рейда (`GetInstanceInfo`: difficulty, maxPlayers).
- Оформление ElvUI для окон этапа 1 (разбор боя) — тем же `addon/skin.lua`, если их виджеты несут `kind`.

## Чего не делать

- Напоминаний про твист тотемов: в WotLK Windfury Totem — постоянная аура, твист умер в TBC.
- API из Cata и позже: `ActionButton_ShowOverlayGlow`, `C_Timer`, `Settings.*`; сигнатуры боевого лога 4.x (`hideCaster`, `raidFlags`). Таймеры — через `OnUpdate`.
- Нажимать кнопки за игрока и трогать защищённые рамки в бою (taint).
- Свой счётчик урона — есть Recount/Skada.
- Отдельной PvP-ротации: Purge, кайт и контроль делают прогноз на 6 с бесполезным; `pvp` работает как группа.
- Случайных проков в симуляторе — только ожидаемое значение, иначе пропадёт детерминированность («бит в бит»).
- Всплывашек и обучения в бою, больше одного сообщения за раз, оценок «плохо сыграл» — подавать мягко («можно лучше: …»).
- Цифр урона и сравнения планов на самой ленте — только в подсказке по наведению.
- Настроек цвета, шрифтов, текстур в первых версиях и звуков по умолчанию.
- Bloodlust по таймеру босса; значок «Bloodlust готов» остаётся выключенным по умолчанию.
